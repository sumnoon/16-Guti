# ষোল গুটি · Sholo Guti

### ▶ Play: **[sumnoon.github.io/16-Guti](https://sumnoon.github.io/16-Guti/)**

The traditional Bangladeshi 16-piece board game in 3D, in a village courtyard under a banyan tree.
Runs in any modern browser on desktop or phone; after the first visit it also plays offline and
can be installed from the browser menu.

This repository only holds the published build of the game and is replaced automatically on each release.
